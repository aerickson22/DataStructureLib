# Data Structures Library

+ This is a simple Data Structures Static Library in C
+ List includes and limited to:
...* Single Linked List
...* Double Linked List
...* Ring Buffer
...* Dynamic Array
...* Queue
...* Hash Tables
+ All will be implemented as generic.

# Data Structures
+ TLDR: This will be updated as I implement each with more detailed documentation.
+ Single Linked List Api
...* append(x) - appends x to end of List
...* prepend(x) - appends x to start of List
...* remove_head() - removes head of List
...* contains(x) - search if x is in List
...* getHead() - gets head of list
...* size() - size of List
...* is_empty() - if list is is empty

+ Double Linked List Api
...* append(x) - appends x to end of List
...* prepend(x) - appends x to start of List
...* remove_head() - removes x from head of List
...* remove_tail() - removes x from tail of list
...* contains(x) - search if x is in List
...* get_head() - gets head of list
...* get_tail() - gest tail of list
...* size() - size of List
...* is_empty() - if list is is empty

+ Ring Buffer Api
...* put(x) - inserts elemented at tail
...* get(x) - get element from head
...* is_empty() - if buffer is empty
...* is_full() - if buffer is is full
...* size() - size of buffer

+ Dynamic Array Api
...* push(x) - append element to end of Array
...* at(i) - get element at i in Array
...* set(i, x) - replace element at i with x in Array
...* remove(i) - removes element from i in Array
...* size() - size of Array
...* is_empty() if list is empty
...* capacity() - capacity of list

+ Queue Api 
...* offer(x) - insert an element
...* poll() - get and removes element
...* peek() - looks at the head
...* size() - return size of Queue
...* is_empty() returns if queue is empty

+ Hash Table Api
...* put(key, value) - insert key and value
...* get(key) - gets values from a key
...* remove(key) - removes key and values
...* has(Key) - check if key exists
...* hasValue(value) - check if value exists
...* size() - size of Tables
...* capacity() - capacity of list
...* is_empty() - if list is empty
